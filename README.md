# 🖼️ Tugas 4 Miftahul — Galeri Web Interaktif

**Tugas 4 Miftahul** adalah proyek halaman web sederhana yang dikembangkan untuk menampilkan antarmuka visual menggunakan HTML. 
Proyek ini memuat halaman beranda tunggal yang terintegrasi dengan berbagai aset gambar pendukung.

##✨ Fitur Utama🏠 
Halaman Beranda (indexx.html): Memuat berkas halaman utama yang terstruktur rapi untuk menampilkan antarmuka web.
🖼️ Galeri Foto Visual (foto1.jpg - foto9.jpg): Menampilkan kumpulan aset gambar portofolio atau galeri visual secara langsung pada halaman web. 
⚡ Struktur Ringan & Terpusat: Didesain dalam satu direktori terpadu tanpa kompleksitas folder eksternal yang rumit, sehingga sangat mudah diakses.  
📱 Tataletak Sederhana: Menggunakan struktur HTML dasar untuk menampilkan konten dengan bersih di peramban web
